# FasterSL：快速重载 / 回退到任意节点

杀戮尖塔 2 的 SL（存档 / 读档）mod，单人和多人都能用。多人局正常回档会保留连接，不用重新进大厅；无法完成同步时会中止重载并返回主菜单。

## 用法

| 操作 | 作用 |
|---|---|
| **ESC 菜单 → Save&Load** | 重载当前房间：回到进入这个房间那一刻的状态 |
| **ESC 菜单 →“回退到节点”** | 打开节点列表，回退到本局走过的任意节点。列表打开时按 Esc 关闭 |
| **顶栏“回合”按钮**（仅战斗中） | 下拉列出本场战斗的回合，点一个回到那个回合刚开始（抽完牌、可以出牌）的状态 |

多人局里只有**房主**能用，客户端的 ESC 菜单里不显示这两个按钮。房主操作后，所有人一起回档。F8 不再触发快速 SL。

## 节点列表

- 列表里是本局走过的所有节点，最新的在最上面。每一行显示：第几幕第几层、房间类型、怪物或事件名，以及进入那个节点时你的生命值和金币。
- 点一行，就回到那个节点**刚进入时**的状态。
- 回退是**单向**的：回到某个节点后，它之后的记录会被删掉，不能再"前进"回去。
- 记录只保存在内存里。退回主菜单再继续同一局，记录还在；关掉游戏后就清空了。

## 回合回退

- 原理：先重载到这场战斗的入口，再用游戏自带的战斗回放把之前的操作加速重放到目标回合。重放期间是黑屏并静音，显示快进到了第几回合；回合越多等得越久。
- 黑屏下方有“重置战斗”按钮：放弃回退，直接回到这场战斗开始（和 Save&Load 一样）。重放失败或超时也会自动这样做。
- 多人局：只有房主能看到“回合”按钮。所有人各自在本地重放，全部完成后一起恢复；任何一人失败或房主点了重置，会先通知大家停止，收到全部停止确认后再一起回到战斗开始。“重置战斗”按钮只在房主那边显示。
- 等待停止确认超过 15 秒，或战斗入场同步超过 30 秒，会通知其他玩家中止本次重载并返回主菜单。可以重新组队继续存档。
- 同样是单向的：回到第 N 回合后，后面的回合记录会被删掉。
- 额外回合也单独编号，所有玩家使用同一套回合阶段编号。
- 有起手选牌或自动动作时，完成后才会出现该回合的回退点。回退会保留当时的起手选择。如果有人在其他玩家完成起手选择前已经出牌或进行其他主动操作，该回合不会加入列表；仍可用 Save&Load 重置整场战斗。

## 其他

- **地图绘画**：回档后会保留**这一幕最新的**绘画，多人局里所有人的笔画都会保留。绘画是按幕记录的，回到上一幕时显示的是上一幕最后的绘画。
- **提示语言**：跟随游戏设置里的语言，支持游戏自带的 16 种语言。识别不了的语言显示英文。
- **游戏版本**：同一个 dll 同时支持正式版 v0.107.1 和 Public Beta v0.111.0。两个版本不一样的接口会在运行时自动识别，见 `src/LobbyCompat.cs`。

## 安装

把 `FasterSL` 文件夹（里面是 `FasterSL.dll` 和 `FasterSL.json`）放进 `<游戏根目录>\mods\`。

> **多人注意**：这个 mod 会新增联机消息类型，并且标记为影响玩法，所以**所有人必须装同一版本**，游戏版本也必须相同，否则进不了同一个房间。和没装这个 mod 的朋友联机时，请先把 `mods\FasterSL` 移出去。

从旧版（MpReloadProto）升级时，先删除 `mods\MpReloadProto` 文件夹，否则新旧两个版本会同时加载。

## 编译

```
dotnet build -c Release -p:Sts2GameDir=<游戏根目录> -p:InstallToGame=true
```

也可以先设置环境变量 `STS2_GAME_DIR`，就不用传 `Sts2GameDir`。

## 日志

日志位置是 `%APPDATA%\SlayTheSpire2\logs\godot.log`，要在重新打开游戏之前复制，否则会被覆盖。带 `[FasterSL]` 的行是本 mod 输出的，只记录重载的开始、完成和出错信息。
